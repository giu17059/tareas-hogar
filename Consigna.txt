Guía de Trabajo Práctico 2: Aplicación del Ciclo 
de Build-Measure-Learn
Objetivo: Aplicar el ciclo de Build-Measure-Learn en el desarrollo de una 
aplicación móvil.
Material Necesario: 
• Libro: "Lean Mobile App Development" 
• Herramientas de desarrollo móvil (Android Studio o Xcode) 
• Acceso a Firebase 
Actividades: 
1. Definición del MVP 
◦ Leer el capítulo 6. 
◦ Definir el Producto Mínimo Viable (MVP) para la aplicación elegida. 
2. Construcción del MVP 
◦ Implementar las características básicas del MVP utilizando Android 
Studio o Xcode. 
◦ Configurar Firebase para la autenticación de usuarios. 
3. Medición y Aprendizaje 
◦ Realizar pruebas con usuarios reales. 
◦ Recopilar datos sobre el uso y analizar los resultados. 
4. Tarea de Diagrama de Arquitectura 
◦ Actualizar el diagrama de arquitectura basado en los resultados 
obtenidos. 
◦ Incluir componentes adicionales necesarios para mejorar la 
aplicación. 
Entregables: 
1.Definición del MVP. 
2.Código del MVP. 
3.Resultados de las pruebas y análisis. 
4.Diagrama de arquitectura actualizado.
